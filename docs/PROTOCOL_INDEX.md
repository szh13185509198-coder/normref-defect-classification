# Protocol index

Every protocol in `docs/` was committed to the development repository before the outputs it governs. This public
repository starts with a fresh history, so the table below records, for each protocol, the commit that first added
it and the last commit that changed it (abbreviated hashes, local time UTC+8). The development history spans two
local repositories: the original working repository (until 2026-10-03) and the repository it was migrated into,
whose first commit carries the migrated files unchanged; first commits are therefore taken from the original
repository.
Later commits of a protocol are amendments recorded inside the protocol itself (for example "P19-A1") or
corrections that do not change a decision rule; Supplementary Material S2 lists the order of information use and
every deviation.

The protocol files are kept byte-identical to their committed versions (the P6.B runner also verifies the SHA-256 of
its protocol and addenda before a formal run). Protocols written in Chinese have an English translation in
[`translations/`](translations/) that keeps the structure, numbers and decision rules of the original.
