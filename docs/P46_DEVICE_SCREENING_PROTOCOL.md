# P46 — The screening guarantee on the deployed engine (report only)

Status: **LOCKED BEFORE ANY P46 OUTPUT** (2026-10-03, user decision). Sequentially added; disclosed in S2. No method,
constant or earlier result changes. Code: `experiments/p46/screen_device.py`.

Data: `p46_ext_pack.tar` (SHA256 83356c62…), holding the VisA (11 objects) and MTD tasks of P15:
- the P15 bank draws (5 seeds, M = 20);
- the P15 calibration sets (N = 100);
- all query images;
- the unit list `P46_UNITS.json`, generated by the P15 rules.

## 1. Question
Does the split-conformal false-reject guarantee of the two-stage inspection (§5.6, Table 10, P15) still hold when the
screening scores come from the deployed single TensorRT engine (P41: GPU preprocessing, FP16 head) instead of the
PyTorch evaluation path?

## 2. Device run (MAXN_SUPER, locked; Claude over SSH, normal user)
- **Engine and preprocessing**: `main_fused_r8.engine` with `fused_engine.gpu_prep`, the deployed path. Each needed
  image is preprocessed once per task.
- **Bank**: per task and seed, the bank tokens come from the engine (tokens output, zero bank input).
- **Screening score**: for every calibration and query image, the engine's own `screen` output with that seed's bank
  (the P15 top-1 % statistic, computed inside the engine). τ and the prototypes do not enter `screen`; dummy prototypes
  are used.
- **Output**: per task and seed, the calibration and query scores, written once.

## 3. Local analysis
Per task and seed, computed the same way as in P15:
- the thresholds τ_α for α ∈ {1 %, 2 %, 5 %}: the k-th smallest calibration score, k = ⌈(N + 1)(1 − α)⌉;
- the realized false-reject rate on the normal queries;
- AUROC (normal vs defect queries).

Reported:
- **Aggregates**: VisA object macro over seeds, and MTD, exactly as the P15 aggregates.
- **Comparison with the saved P15 PyTorch unit values**: per-unit AUROC and false-reject-rate differences.
- **Guarantee check**: whether the realized false-reject rate stays at or below α on VisA (macro) and MTD.

Descriptive; no selection.
